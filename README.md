# DLLM Delta Compute

This repository is the base for the new DLLM Delta Compute project.

## Git remotes

- `origin`: git@github.com:thedannyliu/DLLM-Delta-Compute.git (primary repository)

## Dream dependency

The project uses the Dream stack via a git submodule:

```bash
git submodule update --init --recursive
```

The submodule lives in `external/Dream` and points to `git@github.com:thedannyliu/Dream.git`.
